## 🚀 Publicación / GitHub Pages

Para publicar este sitio web de forma gratuita y segura mediante **GitHub Pages**:

1. En el repositorio de GitHub, dirígete a **Settings** > **Pages**.
2. En la sección **Build and deployment** > **Branch**:
   - Selecciona la rama `main`.
   - Selecciona la carpeta `/ (root)`.
3. Haz clic en **Save**.
4. En unos minutos, el sitio web estará publicado en:
   `https://ahk2001.github.io/motor/`
